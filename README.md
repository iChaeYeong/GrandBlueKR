# GrandBlueKR
그랑블루대구경북 프리다이빙 웹사이트

## 프로젝트 소개
그랑블루대구경북의 프리다이빙 교육, 투어 프로그램, 시설 안내 등을 제공하는 웹사이트입니다.

## 기술 스택
- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion

## 시작하기

개발 서버 실행:
```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 확인할 수 있습니다.

## 배포
이 프로젝트는 Vercel을 통해 배포됩니다.
